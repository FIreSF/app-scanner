# Mobile Application Security Assessment — Report Template

> Structure adapted from the **OWASP WSTG Reporting Structure**
> (https://github.com/OWASP/wstg/blob/master/document/5-Reporting/01-Reporting_Structure.md)
> for mobile assessments, with an **OWASP MASVS v2.0 coverage** section.
> Generated by `scripts/report_builder.py` (`reporting-agent`); this file documents the template.
> A report is written only from findings that passed the lifecycle + 7-question Hard FP Gate,
> and only with explicit user approval (`--approve`).

authorized devices/emulators, using owned test accounts only.

### 1.3 Limitations

- Point-in-time assessment; the app/backend may change after testing.
- Out-of-scope areas, broken functionality, missing credentials, device tooling gaps.

### 1.4 Timeline

### 1.5 Disclaimer

*This test is a point-in-time assessment; the environment may have changed since testing.
There is no guarantee every possible issue was identified. This report is a guiding document,
not a warranty that it fully represents the risks to the system.*
